# Pokémon data and artwork

The gallery requests the first 100 Pokémon names from [PokeAPI](https://pokeapi.co/api/v2/pokemon?limit=100) when it loads.

The app does not fetch or redistribute PokeAPI sprites. Its public API availability does not grant rights to the images. Until artwork with verified reuse rights is provided, cards use the locally authored generic placeholder at `public/pokemon-placeholder.svg`.
